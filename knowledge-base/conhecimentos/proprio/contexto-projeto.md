## Resumo

Documento de contexto geral do projeto st.js — base de prompts, agentes, skills e conhecimentos para conectar modelos de IA.

> **Nota:** Este é um arquivo de rascunho. Substitua pelo contexto real do seu projeto.

## Contexto / Background

Este repositório centraliza recursos de IA (prompts, agentes, skills e conhecimentos) para facilitar a conexão e integração com modelos de linguagem de grande escala (LLMs).

## Objetivos do Projeto

- [ ] Criar uma biblioteca reutilizável de prompts testados e documentados
- [ ] Documentar agentes autônomos e semi-autônomos prontos para uso
- [ ] Catalogar skills modulares combináveis
- [ ] Manter uma base de conhecimento contextual para RAG e system prompts

## Público-Alvo

- Desenvolvedores que trabalham com LLMs
- Times de produto que integram IA em seus fluxos
- Pesquisadores que testam capacidades de modelos
