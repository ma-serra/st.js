# 🏷️ Tags — Lista Mestre

Esta é a lista oficial de tags usadas em toda a base de conhecimento.
Use as tags ao criar novos itens para facilitar a busca e o filtro.

---

## 📂 Por Categoria Principal

| Tag | Descrição |
|-----|-----------|
| `#prompt` | Prompts de texto para modelos de linguagem |
| `#agente` | Agentes autônomos ou semi-autônomos |
| `#skill` | Habilidades / capacidades reutilizáveis |
| `#conhecimento` | Base de conhecimento geral / contextual |

---

## 🔑 Por Origem

| Tag | Descrição |
|-----|-----------|
| `#proprio` | Criado / customizado pelo dono do repositório |

## Uso das Tags

Ao criar um arquivo de prompt, agente, skill ou conhecimento, adicione um bloco de metadados no topo do arquivo:

```yaml
---
titulo: Nome do Item
tags: [#prompt, #proprio, #codigo, #geracao, #gpt, #estavel]
modelo: GPT-4
versao: 1.0.0
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
---
```
